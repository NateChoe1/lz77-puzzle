LZ77 quine puzzle

Inspired by Will Greenberg's implementation of this puzzle, which itself was inspired by some now-defunct webpage. This site adds a few enhancements to allow for some significantly harder puzzles.

There are two commands, corresponding to the two actions in an LZ77 encoded document:

  • print n Copy the next n lines of the input to the output
  • repeat length offset Repeat length lines of output, starting offset lines from the end.

You can also add a header and footer to your quine as would be seen in a real LZ77 encoded document using the <<<<< and >>>>> directives, as in the following:


This is a header,
it won't be printed
to the output
<<<<<
print 4
Hello world!
This text
will be
shown.
>>>>>
This is a footer,
it also won't be
printed to the
output.

Puzzles

You are allowed to add headers and footers to solve any of these puzzles, except where explicitly forbidden.

  1. Create an input which outputs itself when decompressed.
  2. Find a general method to produce these inputs given some arbitrary header and footer.
  3. Find an input which outputs its own data when decompressed twice (but not when it's decompressed only once).
  4. Find a general method to create loopy quines of any order.
  5. Find a general method to create loopy quines of any order, where each level can have some arbitrary header.
  6. Find a general method to create loopy quines of any order, where each level can have some arbitrary header and footer (I haven't solved this one).
  7. Create an input which is at most 10 lines long that decompresses three times to an output of at least 500 lines, where each repeat() instance repeats no more than 5 lines of output.
  8. Create an input which could decompress infinitely, where each level of decompression increases the output size.
