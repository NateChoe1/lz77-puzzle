This is a solution to puzzle 5. This payload is an order 3 loopy quine, where
each level has a different header of different length. The challenging part
about getting this to work is the fact that each payload can have a different
length, so you can't rely on a single repeat instruction to work. You can,
however, rely on the fact that repeat instructions are constant length, so once
you've solved puzzle 4 you can set up 3 different repeat instructions and use
the puzzle 4 payload to alternate between them.
